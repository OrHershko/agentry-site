Agentry support

Agentry is a native iPhone client for a self-hosted, open-source AI agent server. You run the server; Agentry connects to it with the address and the username and password you set up.

Get help

Open an issue describing what you did, what you expected and what happened. Never post passwords, keys or private conversations.

Common problems

  • The app says Offline: your server is not running or not reachable from the phone. Check that it is started and that Tailscale (or your network) is connected.
  • Sign-in fails: use the server's own username and password, not a model provider key.
